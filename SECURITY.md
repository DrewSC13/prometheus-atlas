# Security Policy — Prometheus Atlas

## Reporting a Vulnerability

If you discover a vulnerability:

- do NOT open a public issue
- report privately

Include:

- description
- reproduction steps
- impact
- affected version

---

## Response Process

1. Acknowledgement
2. Investigation
3. Fix development
4. Patch release

---

## Scope

Relevant areas:

- network handling
- parsing external data
- persistence layer
- plugins

---

## Best Practices

- keep dependencies updated
- run static analysis tools
- validate external inputs
