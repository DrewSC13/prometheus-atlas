# Vision — Prometheus Atlas

Prometheus Atlas is a platform designed to analyze how infrastructure exposure evolves over time.

## Core Idea

Security problems are not only about assets.

They are about **change in exposure**.

---

## Problem

Most tools answer:

"What exists?"

Few tools answer:

- what changed
- when it changed
- if it is recurring
- if it increases risk

---

## Solution

Atlas models infrastructure as a time-evolving system:

Snapshot → Diff → Drift → Timeline → Episodes

---

## Key Concepts

- change as primary signal
- drift semantics
- explainability
- historical memory
- correlated events

---

## Goal

Build a platform capable of:

**Security Drift Intelligence**
