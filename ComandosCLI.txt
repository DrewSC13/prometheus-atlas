PROMETHEUS ATLAS - COMANDOS CLI
================================

Versión actual de referencia: v0.20.0
Propósito: operar escaneo, snapshots, drift, grafos, queries, reportes, scheduler, jobs y gestión operativa de hallazgos.

--------------------------------------------------
0. NOTAS GENERALES
--------------------------------------------------

0.1. Ejecutar CLI
    Todos los comandos se ejecutan así:

    cargo run -p atlas -- <comando> [opciones]

0.2. Target de ejemplo
    En este documento se usa:
    example.com

0.3. Salidas JSON
    Muchos comandos soportan:
    --json
    --output archivo.json

0.4. Persistencia
    Algunos comandos permiten guardar resultados en storage con:
    --persist

0.5. Archivos de laboratorio
    Para pruebas de diff/drift:
    lab/old_snapshot.json
    lab/new_snapshot.json
    lab/policy.json


==================================================
1. INICIALIZACIÓN Y CONFIGURACIÓN
==================================================

1.1. Inicializar configuración por defecto
    Qué hace:
    - Crea atlas.toml si no existe
    - Inicializa la base de datos/storage

    Comando:
    cargo run -p atlas -- init

1.2. Inicializar configuración en ruta específica
    Qué hace:
    - Crea un archivo de configuración personalizado

    Comando:
    cargo run -p atlas -- init --output atlas.toml

1.3. Ver perfiles disponibles
    Qué hace:
    - Lista perfiles de escaneo configurados en atlas.toml

    Comando:
    cargo run -p atlas -- profiles

1.4. Ver perfiles en JSON
    Comando:
    cargo run -p atlas -- profiles --json --output profiles.json


==================================================
2. ESCANEO Y SNAPSHOTS
==================================================

2.1. Escanear un target
    Qué hace:
    - Descubre IPs, subdominios y servicios HTTP

    Comando:
    cargo run -p atlas -- scan example.com

2.2. Escanear con salida JSON
    Comando:
    cargo run -p atlas -- scan example.com --json --output scan.json

2.3. Crear snapshot
    Qué hace:
    - Ejecuta escaneo y guarda snapshot en .snapshots

    Comando:
    cargo run -p atlas -- snapshot example.com

2.4. Crear snapshot y persistir en storage
    Comando:
    cargo run -p atlas -- snapshot example.com --persist

2.5. Crear snapshot en directorio personalizado
    Comando:
    cargo run -p atlas -- snapshot example.com --dir .snapshots

2.6. Listar snapshots persistidos
    Qué hace:
    - Lista snapshots registrados en base de datos

    Comando:
    cargo run -p atlas -- snapshots example.com


==================================================
3. DIFF Y DRIFT
==================================================

3.1. Comparar dos snapshots
    Qué hace:
    - Detecta nuevos/removidos/modificados entre snapshots

    Comando:
    cargo run -p atlas -- diff lab/old_snapshot.json lab/new_snapshot.json

3.2. Comparar dos snapshots con JSON
    Comando:
    cargo run -p atlas -- diff lab/old_snapshot.json lab/new_snapshot.json --json --output diff.json

3.3. Analizar drift sin policy
    Qué hace:
    - Genera hallazgos analíticos a partir del diff

    Comando:
    cargo run -p atlas -- drift lab/old_snapshot.json lab/new_snapshot.json

3.4. Analizar drift con policy
    Qué hace:
    - Aplica allowlists, baseline, critical resources y excepciones

    Comando:
    cargo run -p atlas -- drift lab/old_snapshot.json lab/new_snapshot.json --policy lab/policy.json

3.5. Analizar drift con persistencia
    Comando:
    cargo run -p atlas -- drift lab/old_snapshot.json lab/new_snapshot.json --persist

3.6. Drift en JSON
    Comando:
    cargo run -p atlas -- drift lab/old_snapshot.json lab/new_snapshot.json --json --output drift.json

5. QUERY DSL
==================================================

5.1. Query simple por tecnología
    Comando:
    cargo run -p atlas -- query example.com 'services technology=cloudflare'

5.2. Query con EXPLAIN
    Qué hace:
    - Muestra por qué un nodo matcheó la query

    Comando:
    cargo run -p atlas -- query example.com 'EXPLAIN services connected_to=admin.example.com AND in_episode=true'

5.3. Query con expansión de vecinos
    Qué hace:
    - Expande nodos relacionados a N saltos

    Comando:
    cargo run -p atlas -- query example.com 'services technology=cloudflare EXPAND 1'

5.4. Query expandiendo desde un label
    Comando:
    cargo run -p atlas -- query example.com 'label=admin.example.com EXPAND 2'

5.5. Modo NEIGHBORS
    Qué hace:
    - Trae vecinos hasta cierta profundidad

    Comando:
    cargo run -p atlas -- query example.com 'NEIGHBORS label=example.com DEPTH 2'

5.6. Modo NEIGHBORS sobre resultados filtrados
    Comando:
    cargo run -p atlas -- query example.com 'NEIGHBORS services technology=cloudflare DEPTH 1'

5.7. Modo PATH
    Qué hace:
    - Busca camino entre nodo origen y nodo destino

    Comando:
    cargo run -p atlas -- query example.com 'PATH example.com -> cloudflare'

5.8. PATH entre subdominio y servicio
    Comando:
    cargo run -p atlas -- query example.com 'PATH admin.example.com -> "https://admin.example.com"'

5.9. Query con JSON
    Comando:
    cargo run -p atlas -- query example.com 'services technology=cloudflare' --json --output query.json

6. QUERIES GUARDADAS
==================================================

6.1. Guardar query
    Qué hace:
    - Guarda una query reutilizable en storage

    Comando:
    cargo run -p atlas -- query-save risky-admin 'services (title~admin OR label~admin) AND tls_enabled=false'

6.2. Listar queries guardadas
    Comando:
    cargo run -p atlas -- query-list

6.3. Listar queries guardadas en JSON
    Comando:
    cargo run -p atlas -- query-list --json --output query_list.json

6.4. Ejecutar query guardada
    Comando:
    cargo run -p atlas -- query-run risky-admin example.com

6.5. Ejecutar query guardada con límite
    Comando:
    cargo run -p atlas -- query-run risky-admin example.com --limit 10

6.6. Ejecutar todas las queries guardadas
    Qué hace:
    - Corre todas las queries guardadas sobre el target

    Comando:
    cargo run -p atlas -- query-run-all example.com

6.7. Ejecutar todas las queries guardadas en JSON
    Comando:
    cargo run -p atlas -- query-run-all example.com --json --output query_run_all.json

6.8. Eliminar query guardada
    Comando:
    cargo run -p atlas -- query-delete risky-admin

14. OBSERVACIONES IMPORTANTES
==================================================

14.1. Si un subcomando aparece como "unrecognized subcommand"
    Significa que todavía no está implementado en tu main.rs actual o no compilaste la versión correcta.

14.2. Si un finding-id falla
    Verifica que el ID esté completo.
    Ejemplo correcto:
    3af898c74641e919b166da1e

14.3. Si PATH no encuentra nodo origen o destino
    Puede significar:
    - el nodo no existe en el grafo persistido
    - el label exacto no coincide
    - aún no reconstruiste el grafo con los snapshots correctos

14.4. Si timeline/episodes salen vacíos
    Puede ser normal si entre snapshots no hubo cambios reales relevantes.

14.5. Después de cambios grandes
    Conviene correr:
    cargo fmt
    cargo clippy --workspace --all-targets --all-features -- -D warnings
    cargo test --workspace
    cargo build --workspace
